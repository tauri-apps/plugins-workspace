## Default Permission

This permission set configures which
torch features are by default exposed.

#### Granted Permissions

It allows all torch related features.

#### This default permission set includes the following:

- `allow-disable`
- `allow-enable`
- `allow-is-available`
- `allow-is-enabled`
- `allow-toggle`
