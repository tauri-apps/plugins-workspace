## Default Permission

This permission set configures which
camera features are by default exposed.

#### Granted Permissions

It allows all camera related features.

#### This default permission set includes the following:

- `allow-get-photo`
- `allow-pick-images`
- `allow-check-permissions`
- `allow-request-permissions`
